# Typen

| Typ | Verzeichnis | Zweck |
|---|---|---|
| article | 50-Sources/Articles | Ein Beitrag in einem größeren Werk: Zeitschrift, Zeitung, Sammelband. |
| book | 50-Sources/Books | Ein Werk für sich: Monographie, Sammelband, Bericht. |
| bundle | 40-Wiki/Bundles | Beschreibt eine Lieferung. |
| city | 40-Wiki/Cities | Eine Stadt. |
| clipping | 50-Sources/Clippings | Eine erfasste Webseite; ihr Text steht im Body der Notiz. |
| comparison | 40-Wiki/Comparisons | Eine Gegenüberstellung mehrerer Gegenstände entlang benannter Dimensionen. |
| concept | 40-Wiki/Concepts | Eine Sache und der Stand des Wissens über sie. |
| country | 40-Wiki/Countries | Ein Staat. |
| event | 40-Wiki/Events | Ein Geschehen zu einer bestimmten Zeit. |
| hint | 40-Wiki/Hints | Eine Festlegung, wie diese Wissensbasis geführt wird. |
| note | 40-Wiki/Notes | Eine Notiz ohne spezifischeren Typ. |
| organisation | 40-Wiki/Organisations | Eine Körperschaft: Unternehmen, Institut, Verein, Behörde. |
| person | 40-Wiki/Persons | Ein Mensch. |
| place | 40-Wiki/Places | Ein geographischer Ort. |
| proptype | 90-System/Proptypes | Schränkt eine Wertform ein. |
| specification | 40-Wiki/Specifications | Ein normatives Dokument, an das sich die Wissensbasis hält. |
| term | 40-Wiki/Terms | Ein definierter Begriff. |
| topic | 40-Wiki/Topics | Ein Themengebiet als Einstiegspunkt. |
| typedef | 90-System/Typedefs | Registriert einen Typ und legt sein Verzeichnis fest. |
| webpage | 50-Sources/Webpages | Eine zitierte Webseite; ihr Text bleibt draußen. |
